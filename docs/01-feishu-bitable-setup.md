# 第一步：创建飞书多维表格、3 个自动公式列与 8 大仪表盘图表

本指南带你从零搭建一套支持**「日常消费账本 + 副业/项目账本」**的双账本飞书多维表格（Bitable）。你可以选择**方式 A（脚本一键建表，30 秒完成）**，或**方式 B（在飞书网页端手动建表，3 分钟完成）**。

---

## 一、核心字段架构说明（为什么这么设计？）

为了让 iPhone 快捷指令写入速度最快、配置最简单，同时又能支撑专业级的可视化仪表盘，我们采用**「5 个基础写入列 + 3 个自动公式列」**的设计：

### 1. 基础字段（由 iPhone 快捷指令或 API 写入）

| 字段名称 | 飞书字段类型 | 格式 / 属性设置 | 作用说明 |
| :--- | :--- | :--- | :--- |
| **`事件`** | 文本（主列 / 第一列） | 默认文本 | 记录消费或收入的具体摘要（如：`午餐`、`地铁通勤`、`项目回款`、`显示器支架`） |
| **`收支`** | 数字（Number） | 保留 **2 位小数** (`0.00`) | **核心有符号金额列**：**正数表示收入**（如 `500.00`），**负数表示支出**（如 `-35.50`）。快捷指令会根据你选的是「收入」还是「支出」自动带上正负号！ |
| **`标签`** | 文本（Text） | 默认文本 | 通用分类纯文本标签（方便全文检索或跨表汇总） |
| **`分类`** | 多选 或 单选 | 预设通用分类标签 | 彩色标签列，用于直观筛选与分组（如：`餐饮`、`交通`、`购物`、`居住水电`、`娱乐休闲`、`医疗健康`、`主业收入`、`副业收入`、`采购成本`、`运营支出`、`设备工具`） |
| **`时间`** | 日期（Date） | 格式 `yyyy/MM/dd`，勾选**「新记录自动填入创建时间」** | 记录发生日期。开启自动填入创建时间后，快捷指令无需传时间戳即可自动记在当天！ |
| **`渠道`** | 文本（可选） | 默认文本 | 支付或收款方式（如：`微信支付`、`支付宝`、`银行卡`、`现金`） |

### 2. 三个自动计算公式列（供仪表盘图表聚合统计）

为什么有了 `收支` 列还要加 3 个公式列？因为飞书多维表格的柱状图、饼图在统计「支出占比」或「收入 vs 支出双柱对比」时，需要正数形式的独立 `收入` 列和 `支出` 列，以及按月聚合的 `月份` 列：

| 公式字段名 | 飞书字段类型 | 精确公式表达式（直接复制粘贴） | 数字/显示格式 | 作用说明 |
| :--- | :--- | :--- | :--- | :--- |
| **`收入`** | 公式（Formula） | `IF([收支]>0,[收支],0)` | 数字 `0.00` | 当 `收支` 大于 0 时取该值，否则为 `0`（自动过滤出所有收入） |
| **`支出`** | 公式（Formula） | `IF([收支]<0,ABS([收支]),0)` | 数字 `0.00` | 当 `收支` 小于 0 时取其正数绝对值 `ABS([收支])`，否则为 `0`（方便饼图/柱状图按正数统计支出） |
| **`月份`** | 公式（Formula） | `TEXT([时间],"YYYY/MM")` | 默认文本 | 自动将日期提取为 `"2026/10"` 格式文本，用于按月汇总趋势图 |

## 二、方式 A：使用脚本一键创建表结构与公式列（推荐）

如果你已经在飞书创建好了一个空白多维表格，并获取了它的 `app_token`（见下方第四节如何从浏览器地址栏复制 `app_token`）：

### 选项 1：使用纯 Node.js 脚本 `tools/init-bitable.mjs`（零依赖）

```bash
# 预览将要发送的 API 请求体（不发起真实网络请求）
node tools/init-bitable.mjs --dry-run

# 填入你的飞书自建应用凭证与多维表格 App Token，一键创建「副业项目账本」+「日常消费账本」及全部公式列，并写入示例数据：
FEISHU_APP_ID="cli_xxxxxxxxxxxxxxxx" \
FEISHU_APP_SECRET="你的32位AppSecret" \
FEISHU_APP_TOKEN="你的多维表格AppToken" \
node tools/init-bitable.mjs --insert-sample
```

脚本运行成功后，会直接打印出两条可直接粘贴进 iPhone 快捷指令的 `recordUrl`！

### 选项 2：使用飞书官方 `lark-cli` 脚本 `tools/init-lark-cli.sh`

```bash
# 预览命令与 8 大仪表盘配置指南
bash tools/init-lark-cli.sh --dry-run

# 使用已登录的 lark-cli 执行初始化
FEISHU_APP_TOKEN="你的多维表格AppToken" bash tools/init-lark-cli.sh
```

## 三、方式 B：在飞书网页端手动建表（纯鼠标操作，3 分钟完成）

1. 打开飞书电脑端或网页版，进入**「云文档」** → 点击左上角 **「+ 新建」** → 选择 **「多维表格」**。
2. 将新建的多维表格命名为 **`个人与副业双账本`**（或者分别创建两个多维表格文档：`日常消费账本` 与 `副业项目账本`）。
3. **重命名第一个数据表为 `日常消费账本`**，按以下顺序调整列：
   - 将第 1 列（主列，文本类型）重命名为 **`事件`**。
   - 点击右侧 `+` 新增列：
     - 名称 **`收支`** → 类型选 **「数字」** → 格式选 **「保留 2 位小数 (0.00)」**。
     - 名称 **`标签`** → 类型选 **「文本」**。
     - 名称 **`分类`** → 类型选 **「多选」**（或「单选」），添加选项：`餐饮`、`交通`、`购物`、`居住水电`、`娱乐休闲`、`医疗健康`、`人情往来`、`其他消费`、`主业工资`、`奖金补贴`、`理财收益`、`闲置转让`、`其他收入`。
     - 名称 **`时间`** → 类型选 **「日期」** → 日期格式选 `yyyy/MM/dd`，**务必打开「新记录自动填入创建时间」开关**。
     - 名称 **`渠道`** → 类型选 **「文本」**。
4. **添加 3 个公式列（支持双账本按月净结余联动方案 A）**：
   - 点击 `+` → 类型选 **「公式」** → 字段名填 **`收入`**：
     - **日常消费账本（联动版）**粘贴：`IF([标签]="生意结余",[收支],IF([收支]>0,[收支],0))`
     - **副业项目账本**粘贴：`IF([收支]>0,[收支],0)`
     - 在下方格式设置中选择数字 `0.00`。
   - 点击 `+` → 类型选 **「公式」** → 字段名填 **`支出`**：
     - **日常消费账本（联动版）**粘贴：`IF([标签]="生意结余",0,IF([收支]<0,ABS([收支]),0))`（确保某月副业净结余为负时仅冲减总收入，不虚增日常消费支出）
     - **副业项目账本**粘贴：`IF([收支]<0,ABS([收支]),0)`
     - 格式选择数字 `0.00`。
   - 点击 `+` → 类型选 **「公式」** → 字段名填 **`月份`** → 粘贴公式：`TODATE([时间],"YYYY/MM")`（或 `TEXT([时间],"YYYY/MM")`）。
5. **一键复制出第二张表 `副业项目账本`**：
   - 在左侧数据表列表，点击 `日常消费账本` 右侧的 `...` → 选择 **「复制数据表」** → 命名为 **`副业项目账本`**，这样所有公式列都会自动保留，只需把 `分类` 选项调整为：`主业收入`、`副业收入`、`项目回款`、`咨询服务`、`采购成本`、`运营支出`、`软件云服务`、`办公耗材`、`交通物流`、`设备工具`、`其他支出`。

## 四、搭建 8 大可视化仪表盘看板（Dashboard）

在飞书多维表格左侧栏点击 **「+ 新建仪表盘」**，添加以下 **8 个核心图表组件**，即可获得实时自动更新的财务驾驶舱：

| 序号 | 组件名称 | 图表类型 | 数据配置明细 |
| :---: | :--- | :--- | :--- |
| **1** | **总收入** | **统计数字（数字卡）** | 统计方式：**汇总值** → 字段选 **`收入`** → **求和 (SUM)**（前缀填 `¥`） |
| **2** | **总支出** | **统计数字（数字卡）** | 统计方式：**汇总值** → 字段选 **`支出`** → **求和 (SUM)**（前缀填 `¥`） |
| **3** | **净结余** | **统计数字（数字卡）** | 统计方式：**汇总值** → 字段选 **`收支`** → **求和 (SUM)**（因正负抵消，直接求和即净结余！） |
| **4** | **记账笔数** | **统计数字（数字卡）** | 统计方式：**记录总数 (COUNT)**（后缀填 `笔`） |
| **5** | **月度收支三柱对比** | **柱状图（分组柱状图）** | 横轴 (X)：**`月份`**（升序）；纵轴 (Y)：同时添加 **`收入` (求和)**、**`支出` (求和)**、**`收支` (求和)** |
| **6** | **月度横向条形图** | **条形图** | 纵轴维度：**`月份`**；横轴数值：**`收入` (求和)** 与 **`支出` (求和)** |
| **7** | **各分类支出占比** | **饼图 / 环形图** | 分类维度：**`标签`**（或 **`分类`**）；数值指标：**`支出` (求和)**（筛选条件可设 `支出 > 0`） |
| **8** | **每月净结余趋势** | **折线图** | 横轴 (X)：**`月份`**（升序）；纵轴 (Y)：**`收支` (求和)**（开启平滑曲线与数值标签） |

## 五、如何从浏览器地址栏获取 `APP_TOKEN` 和 `TABLE_ID`？

在电脑浏览器中打开你的飞书多维表格，观察地址栏 URL：

```text
https://xxx.feishu.cn/base/bascnXXXXXXXXXXXXXXXX?table=tblYYYYYYYYYYYYYY&view=vewZZZZZZ
                           \___________________/       \_______________/
                                    |                          |
                        你的 APP_TOKEN (应用标识)     当前表的 TABLE_ID (数据表标识)
```

> **注意**：如果你的多维表格创建在「知识库（Wiki）」目录下，URL 形如 `https://xxx.feishu.cn/wiki/wikcn...`。为了方便直接获取 `base/` 开头的 `APP_TOKEN`，建议直接在**「云文档 → 我的空间」**下新建多维表格，或者使用 `tools/init-bitable.mjs` 获取对应的 `table_id`。
