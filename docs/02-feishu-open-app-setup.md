# 第二步：配置飞书开放平台自建应用与文档授权（保姆级教程）

为了让 iPhone 快捷指令能够把账单直接写入你的飞书多维表格（**不经过任何第三方中转服务器**），我们需要在飞书官方开放平台创建一个属于你自己的「企业自建应用」。整个过程完全免费，只需 **3 分钟**。

---

## 一、注册飞书个人版/团队版（如果已有飞书账号可跳过）

如果你使用的是个人号且在飞书开放平台提示“无企业权限”，只需在手机飞书 App 内点击左上角头像 → **「创建团队/企业」**，随便起一个名字（如 `个人效率工作室`），人数选 `1-10 人`，无需营业执照认证即可免费拥有完整的开放平台自建应用能力。

---

## 二、创建飞书企业自建应用并获取 `App ID` 与 `App Secret`

1. 用电脑浏览器打开 **[飞书开放平台开发者后台](https://open.feishu.cn/app)** 并扫码登录。
2. 点击 **「创建企业自建应用」**：
   - **应用名称**：填 `自动记账助手`
   - **应用描述**：填 `iPhone 快捷指令多维表格自动记账`
   - 点击 **「创建」**。
3. 进入应用详情页后，点击左侧菜单栏第一项 **「凭证与基础信息」**：
   - 复制保存你的 **`App ID`**（以 `cli_` 开头，例如 `cli_a1b2c3d4e5f6g7h8`）。
   - 复制保存你的 **`App Secret`**（点击眼睛图标查看 32 位密钥字符串）。
   > **安全提醒**：`App Secret` 相当于你的应用密码，请只填在自己的 iPhone 快捷指令本地变量中，切勿公开上传到互联网。

---

## 三、开通多维表格权限（`bitable:app`）

1. 在飞书开发者后台左侧菜单栏，点击 **「开发配置」 → 「权限管理」**。
2. 在搜索框中输入 `多维表格` 或 `bitable:app`。
3. 勾选以下权限（建议直接勾选可读可写总权限）：
   - `bitable:app`：**查看、评论、编辑和管理多维表格**
   - （若细粒度勾选，至少包含 `bitable:app:readonly` 与编辑权限）
4. 点击右上角 **「批量开通」** → 确认开通。

---

## 四、添加机器人能力并发布应用版本（必做！）

许多新手配好权限后报错，是因为忘了打开「机器人」能力或忘了发布版本：

1. 点击左侧菜单栏 **「添加应用能力」** → 找到 **「机器人（Bot）」** → 点击 **「+ 添加」**（开启机器人能力后，你的多维表格才能搜到并添加这个应用作为协作者）。
2. 点击左侧菜单栏 **「应用发布」 → 「版本管理与发布」**：
   - 点击右上角 **「创建版本」**：
   - **应用版本号**：填 `1.0.0`
   - **更新说明**：填 `初始发布多维表格记账权限`
   - **可用范围**：选择「全部员工」或「仅管理员自己」
   - 点击底部 **「保存」** → 再点击 **「确认发布」**（个人/小团队默认免审批或自己秒批生效）。

---

## 五、最关键一步：将应用添加为多维表格的「可编辑」协作者

> ⚠️ **90% 的新手第一次调用报 `91403 Forbidden` 都是因为漏了这一步！**
> 即使应用是你创建的，飞书出于安全隔离设计，默认也不允许应用读写你私人的云文档，除非你把该应用拉进对应多维表格的「文档应用 / 协作者」列表。

1. 打开你在第一步创建好的 **飞书多维表格** 页面。
2. 点击页面右上角的 **`...`（更多）图标** → 选择 **「添加文档应用」**（部分版本在右上角「分享 / 协作」弹窗底部）。
3. 在搜索框中搜索你刚刚创建的机器人名称：**`自动记账助手`**。
4. 选中它，并将右侧权限从「可阅读」修改为 **「可编辑」**，点击 **「添加 / 确定」**。
5. 如果你把「日常消费账本」和「副业项目账本」放在了两个不同的多维表格文档里，请给**两个多维表格文档都添加该文档应用（可编辑）**！

---

## 六、用一条命令验证你的接口是否畅通（可选）

完成以上五步后，你可以在电脑终端运行我们仓库自带的初始化脚本，或者用 `curl` 验证 `tenant_access_token` 是否能正常获取：

```bash
curl -s -X POST "https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal" \
  -H "Content-Type: application/json" \
  -d '{"app_id":"你的App_ID","app_secret":"你的App_Secret"}'
```

如果返回 `"code": 0` 且包含 `"tenant_access_token": "t-xxxx"`，说明你的飞书开放平台应用已经 100% 配置成功！
