# 第三步：iPhone 快捷指令

## 导入与配置

下载 `shortcuts/飞书一体账本-通用版.shortcut` 的原始文件，通过 AirDrop、文件或 iCloud 传到手机并打开。导入时填写自己的 App ID、App Secret 和一体账本 records API 地址。

XML 未签名源码用于审计与重建，通常不能直接在 iPhone 导入。Mac 可运行：

```bash
python3 tools/build-shortcut.py
bash tools/sign-shortcut.sh
```

本机签名生成 `shortcuts/Feishu-Unified-Ledger.signed.shortcut`。公开模板的签名回执见 `shortcuts/signing-receipt.json`。以后改了源码需要重新签名，不能把旧签名文件当作新版本。

## 实际操作

1. 打开付款结果页并运行快捷指令。第一次允许截图/识别以及访问 `open.feishu.cn`。
2. 从 OCR 数字候选中选金额。候选可能含时间、订单号；**下一步始终可以修改金额**。没识别到数字则直接手动输入。
3. 确认正数金额（最多两位小数），再选择“生意/项目收入、支出”或“生活收入、支出”。
4. 选分类，然后填写备注。四个入口都显示“请输入备注”；备注保存到“事件”，分类保留所选内容。比如“生活支出 → 购物 → 手机膜”会保存分类“购物”、事件“手机膜”。空白或只有空格的备注不能提交。
5. 飞书返回成功码与记录编号后，才显示“飞书记账完成”。

失败/超时/提示未确认保存时，先去飞书查是否已有该笔。没有自动重发，也没有服务器端幂等键；再次运行可能新增重复记录。

## 分类自定义

编辑 `config/shortcut-config.local.json`（复制示例），可修改常用分类名称；所有分类均必填备注，旧 `ask_note` 选项不再生效。生意收入、支出也可在手机直接选择“自定义分类”，输入本次分类后再填备注，无需编译；该分类不会自动加入快捷指令的固定菜单。保留 `ledger=生意/生活` 和四种方向，`sign=1` 为收入、`-1` 为支出。`生意结余` 由云端专用，不用于手动记账。

```bash
python3 tools/build-shortcut.py --config config/shortcut-config.local.json --output shortcuts/private/MyLedger.shortcut --sign
```

`--sign` 需 Mac；不带该参数的构建可在 Python 3.10+ 环境完成。凭证可以在导入时填写，不必写进本地 JSON。分享填好配置的快捷指令会暴露应用密钥。

## 绑定轻点背面

设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下，选择此快捷指令。也可以从快捷指令 App 或操作按钮运行，具体入口依机型/iOS 版本而定。

## 真机验收清单

本通用构建的动作图测试不等于 iOS 运行测试。请在测试表逐项验证：

- 四个方向各记一次，检查正负号与账本。
- 截图识别 25.50 后修改为 12.34，检查保存的是 12.34；整数、无候选、多候选也测试。
- 零、负数、三位小数不能提交；取消输入不应写入。
- 备注含引号和换行，能完整保存；任何分类下的空白或纯空格备注都不应提交；生意“自定义分类”应能独立填写分类和备注。
- 无权限/断网时不显示成功；恢复后先查表再决定是否重试。
- 时间为当前时刻；公式月份与北京时间一致。
