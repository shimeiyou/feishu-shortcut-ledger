# 第三步：iPhone 快捷指令导入、自定义编译与「轻点背面」触发指南

本仓库同时提供**直接可用的已签名快捷指令模板**、**支持自定义分类的 Python 编译器**，以及**在 iPhone 上纯手工搭建的动作拆解**。

---

## 一、最快方式：直接导入已签名的通用模板（1 分钟）

1. 将本仓库中的 `shortcuts/飞书双账本自动记账-通用模板.shortcut` 通过 AirDrop（隔空投送）、iCloud 云盘、微信文件传输助手或飞书发送到你的 iPhone。
2. 在 iPhone 上点击该文件，系统会自动唤起 **「快捷指令（Shortcuts）」** App 并弹出 **「设置此快捷指令」** 引导页，依次填入 4 个参数：
   - **1/4 `App ID`**：你在飞书开放平台复制的 `cli_xxxxxxxx`
   - **2/4 `App Secret`**：你的 32 位飞书应用密钥
   - **3/4 `副业项目账本 API 地址`**：形如：
     `https://open.feishu.cn/open-apis/bitable/v1/apps/你的APP_TOKEN/tables/你的副业表TABLE_ID/records`
   - **4/4 `日常消费账本 API 地址`**：形如：
     `https://open.feishu.cn/open-apis/bitable/v1/apps/你的APP_TOKEN/tables/你的日常表TABLE_ID/records`
     *(注：如果你只用一张表记所有账，把第 3 项和第 4 项填成同一个地址即可！)*
3. 点击 **「添加快捷指令」** 完成导入！
4. 如果你后续想修改这 4 个参数或分类列表，只需在「快捷指令」App 中点击该捷径右上角的 **`...`**，前 4 个「文本」动作框就是你的配置项，随时可改。

---

## 二、进阶方式：修改 JSON 配置并生成专属分类捷径

如果你想把分类改成更贴合自己职业的选项（例如自由设计师、独立开发者、电商卖家、摄影工作室等）：

1. 复制并编辑 `config/shortcut-config.example.json`：
   - 修改 `menu_top`（顶层四选一菜单名称）
   - 修改 `categories.biz_expense_quick`（副业支出高频一键分类）
   - 修改 `categories.life_expense_list`（日常消费分类列表）
2. 运行生成器脚本：
   ```bash
   python3 tools/build-shortcut.py --config config/shortcut-config.example.json --sign
   ```
3. 脚本会同时输出：
   - `shortcuts/Feishu-Dual-Ledger-Unsigned.shortcut`（未签名 XML Plist 源码，完全透明可审计）
   - `shortcuts/飞书双账本自动记账-通用模板.shortcut`（已签名 AEA1 格式，可直接发到 iPhone 导入）
   > **macOS 用户提示**：如果你在 Mac 上运行 `build-shortcut.py --sign`，脚本会自动优先调用苹果系统自带的 `shortcuts sign --mode anyone` 进行本地签名。

## 三、快捷指令内部工作原理完全拆解（也可以在 iPhone 上照着手动搭）

整个快捷指令由 **3 个阶段** 组成，逻辑非常清晰：

### 阶段 1：截屏 + iOS 原生 OCR + 正则提取金额

1. **【截屏】** (`takescreenshot`)：截取当前微信支付、支付宝或银行 App 的账单完成页。
2. **【从图像中提取文本】** (`extracttextfromimage`)：调用 iOS 本地神经网络引擎离线识别图中文字（图片不会上传到任何外部服务器）。
3. **【匹配文本】** (`text.match`)：
   - 正则表达式：`[0-9]+\.[0-9]{1,3}`
   - 原理：微信/支付宝支付成功页的金额几乎都带有两位小数（如 `35.50`），用该正则能精准提取页面上的金额数字。
4. **【计算数量 + 条件分支】**：
   - 若匹配数量 `= 0`（如整数红包或空白页）：弹出 **【要求输入（数字）】** 让你手动输入金额，存入变量 `money`。
   - 若匹配数量 `> 1`（页面上有原价、立减、实付等多个小数）：弹出 **【从列表中选择】** 让你点选实付金额，存入变量 `money`。
   - 若匹配数量 `= 1`：直接将该数字存入变量 `money`。

### 阶段 2：顶层四选一双账本菜单 + 自动正负号换算

弹出菜单：`记账 ¥[money] 元，请选择账本与收支类型：`

- **分支 1：`副业项目收入`**
  - 绑定地址：`record_url` = `biz_url`
  - 带符号金额：`金额` = `+money`（正数）
  - 从列表中选择收入分类（`主业收入`、`副业收入`、`项目回款`、`咨询服务`、`其他收入`），输入备注 `event`。
- **分支 2：`副业项目支出`**
  - 绑定地址：`record_url` = `biz_url`
  - **【计算】**：`money × -1` → 存入变量 `金额`（自动转为负数，如 `-399`）
  - 从菜单中选择高频支出分类（`采购成本`、`运营支出`、`软件云服务`、`办公耗材`、`交通物流`、`设备工具`、`其他项目支出`）。其中高频固定项无需二次打字即可秒记！
- **分支 3：`日常消费支出`**
  - 绑定地址：`record_url` = `life_url`
  - **【计算】**：`money × -1` → 存入变量 `金额`（负数）
  - 从列表中选择日常分类（`餐饮`、`交通`、`购物`、`居住水电`、`娱乐休闲`、`医疗健康`、`人情往来`、`其他消费`），备注默认填充分类名，直接点「好」即可。
- **分支 4：`日常其他收入`**
  - 绑定地址：`record_url` = `life_url`
  - 带符号金额：`金额` = `+money`（正数）
  - 从列表中选择分类（`主业工资`、`奖金补贴`、`理财收益`、`闲置转让`、`其他收入`）。

### 阶段 3：直连飞书开放平台 REST API 写入多维表格

1. **获取 `tenant_access_token`**：
   - 动作：**【获取 URL 内容】** (`POST https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal`)
   - 请求体 JSON：`{"app_id": "[app_id]", "app_secret": "[app_secret]"}`
   - 动作：**【获取词典值】** → 键名填 `tenant_access_token` → 存入变量 `feishu_token`。
2. **拼接多维表格新增记录请求体 `req_body`**：
   ```json
   {"fields":{"事件":"[event]","收支":[金额],"标签":"[分类]","分类":["[分类]"]}}
   ```
3. **新增记录请求**：
   - 动作：**【获取 URL 内容】** (`POST [record_url]`)
   - 请求头（Headers）：
     - `Authorization`: `Bearer [feishu_token]`
     - `Content-Type`: `application/json`
   - 请求体类型：**文件（File）** → 选择变量 `req_body`
4. **【显示通知】**：弹出横幅 `飞书记账完成：已记入...`。

## 四、绑定 iPhone「轻点背面两下」或「操作按钮（Action Button）」

配置完成后，把它绑定到硬件手势上，实现真正的「付完款敲两下手机背面即记账」：

### 方式 1：轻点背面（iPhone 8 及以上全系支持）
1. 打开 iPhone **「设置」** → **「辅助功能」** → **「触控」**。
2. 滑到最底部，点击 **「轻点背面」**。
3. 选择 **「轻点两下」**（或「轻点三下」）。
4. 下滑到「快捷指令」分区，勾选 **`飞书双账本自动记账-通用模板`**。

### 方式 2：操作按钮 Action Button（iPhone 15 Pro / iPhone 16 及以上支持）
1. 打开 iPhone **「设置」** → **「操作按钮」**。
2. 左右滑动切换到 **「快捷指令」**，选择 **`飞书双账本自动记账-通用模板`**。

### 首次运行权限勾选提示
第一次敲击背面运行该快捷指令时，iOS 会先后弹出两个隐私确认框：
- *“是否允许截屏 / 访问屏幕内容？”* → 请点 **「始终允许」**
- *“是否允许连接到 `open.feishu.cn`？”* → 请点 **「始终允许」**
此后每次记账均全程丝滑无额外授权弹窗！
