# 排错

## 点“查看权限”后窗口消失

Apps Script 首次运行需要 Google 账号授权。若内置浏览器没有打开授权弹窗，把项目 URL **复制到普通 Chrome/Edge 地址栏**，登录同一个账号，选 `previewDailySync` → Run → Review permissions。完成授权后检查执行日志，`Execution completed` 和预演报告才算执行成功，提示框消失本身不算。

## Shortcut 提示参数缺失或日期无效

重新导入当前签名模板；不要在旧版上只替换一个参数。新版数字比较使用数字右值，零也保留；日期动作使用 `WFDateActionDate=1970-01-01T00:00:00Z` 与当前日期输出，再计算毫秒。改 XML 后必须重建并重新签名。真机问题请提供已遮盖 App Secret、表格标识和私人流水的动作截图。

## 飞书权限或字段错误

同时检查：自建应用已发布、API 读写权限已开通、文档添加了该应用并允许编辑、URL 指向正确 Base/表。v2 的 `分类` 是单选字符串，不是旧版多选数组；`时间` 与 `收支` 为数字。91403、99991663、1254045 等错误应结合接口返回的实际信息核对，不要只凭错误码更换账本。

## 显示“未确认保存”

可能请求失败，也可能服务端已经写入但手机没收到响应。**先查飞书原表**，按事件、金额、时间核对。不要不断重复运行，模板没有承诺服务端 exactly-once。成功通知以 Feishu `code=0` 和 `data.record.record_id` 为条件。

## 月结余没有立即变化

手机只负责新增交易。开启云端任务后，月结余默认每天刷新一次，可能滞后到下一次成功任务。检查 Apps Script 执行记录、`LAST_RUN_SUCCESS_AT` 和 `LAST_ERROR`。公式只计算字段，不会自己新增月结余记录。

## 提示“创建结果待核实 / 同月自动汇总重复”

任务停止是为了避免自动创建重复行。先导出/备份该月流水，核对自动汇总的事件、账本、分类、来源、时间与金额。确认此前创建确实未写入，才可在脚本属性 `PENDING_CREATES` 中移除对应月份；不确定时保留并调查。不要清空整个属性来掩盖故障。重复派生行需人工确定保留哪条，脚本不自动删除。

## Sheets 备份失败

不使用备份时不要安装模块，不要设 `BACKUP_ENABLED=true`。使用时检查 `SPREADSHEET_ID`、当前 Google 账号编辑权限、Sheets v4 高级服务及额外授权。明细行数骤降超过 20% 会停止覆盖；核对确实为预期删除后，设一次性 `ALLOW_LARGE_SHRINK=true` 再运行。

备份失败可能发生在月结余刷新已完成之后；以日志与 `LAST_BACKUP_SUCCESS_AT` 为备份判断依据，不要把月结余更新等同于备份成功。错误日志只包含错误类别/代码，不应粘贴密钥或完整流水。

## 能保证永不失败吗

不能。网络、平台权限、调用配额、iOS 版本和服务变化都会影响运行。仓库用回读核验、异常中止和不自动重发创建请求降低风险；定期看任务记录，重要账目保留独立历史导出。Google 脚本锁仅保护同一项目，不能锁住其他脚本或手机；同一表只配置一个月结余写入器。
